#  Week 5: Advanced Layouts & Responsive Design

Mastering modern CSS layout techniques to build responsive and dynamic web interfaces.

---

##  Topics Covered
- **Flexbox**: Efficiently aligning and distributing space among items.
- **CSS Grid**: Creating complex two-dimensional layouts.
- **Responsive Design**: Using media queries for mobile-first development.
- **Tables and Forms**: Styling interactive elements.

---

##  Assignments

- **City Assignment**: Responsive landing page layout.
- **Dashboard**: Implementing a data-rich admin-style interface.
- **Flexbox Practice**: A series of exercises to master `flex-direction`, `justify-content`, and `align-items`.
- **Tables**: Styling structured data for readability (`table1`, `table2`).

---

## Key Files
- `cityassignment.html`
- `dashboard.html`
- `flex/` - Collection of flexbox examples.
- `style.css` - Global stylesheet.

---

## Conclusion
- Building layouts that work on all screen sizes.
- Solving complex alignment issues without floats.
- Creating professional-looking UI components.
